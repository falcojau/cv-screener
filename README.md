# CV Screener

Web app where candidates can submit their CV through a form.

Built with **FastAPI**, **Resend** (email), **Docker**, and vanilla **HTML/CSS/JS**.

https://falcojau.github.io/cv-screener/

## Features

- Upload a CV in PDF format (max 5MB)
- Sends a confirmation email to the candidate
- Forwards the CV as an attachment to HR
